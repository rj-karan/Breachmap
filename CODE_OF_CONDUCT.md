# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good intent, keep criticism about the work and
not the person, and do not harass anyone. Report problems to the maintainer at
the address in `SECURITY.md`. Reports are handled privately and in confidence.
