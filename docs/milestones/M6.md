# M6 — Detect + report

Due: 2027-03-02

## Goal

Paths that stay open are watched, and every path doubles as compliance
evidence.

## Scope

- Sigma rule per `CAN_ASSUME` step on CloudTrail `AssumeRoleWithWebIdentity`
  with unexpected `sub`, generated with pySigma, each shipping a positive and
  a negative sample event.
- Path-correlation rule: two steps of one path inside a window.
- Drift alert when a rescan reopens a closed path, with the diff.
- CIS AWS Foundations and CIS Kubernetes mapping from a versioned mapping
  file that cites benchmark versions; CSV export.
- Mutation test suite generated from the seeded lab (hundreds of mutations),
  pass rate reported in `docs/accuracy.md`.

## Exit test

```
uv run breachmap detect --lab
uv run pytest tests/mutations -q
```

Every exported rule passes its own positive and negative sample. Mutation pass
rate ≥ 95%. No rule that fails its test is exported.
