# M2 — Collectors + graph

Due: 2026-12-08

## Goal

Read live state for the v1 path family and turn it into typed edges that
cannot exist without evidence.

## Scope

- Graph model: node and edge Pydantic types with mandatory evidence,
  evidence level, confidence, observed-at, collector version, fix template.
- GitHub collector: workflows, triggers (`pull_request_target`,
  `workflow_run`, `issue_comment`), `permissions`, `id-token: write`, unpinned
  `uses:`; zizmor findings imported as `CAN_TRIGGER` evidence.
- AWS collector (read-only, `SecurityAudit`-style role): IAM roles and trust
  policies, managed and inline policies, permission boundaries, SCPs, S3
  bucket policies, secret and KMS key policies, OIDC providers.
- Kubernetes collector on kind: service accounts, pods, RBAC, IRSA-style
  annotations (`eks.amazonaws.com/role-arn`).
- Coverage report: what each collector could and could not read.
- Snapshot persistence: versioned JSON snapshot per scan in Postgres.

## Exit test

```
uv run breachmap scan --fixtures lab/fixtures   # offline
uv run breachmap scan --aws --kind              # against the lab
```

Every node and edge in the lab answer key is present in the snapshot with
evidence, and no edge is present without it. The coverage report lists zero
denied calls on the lab.
