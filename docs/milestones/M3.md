# M3 — Accuracy engine

Due: 2026-12-29

## Goal

The evaluator is cross-checked against AWS's own evaluators and Kubernetes'
own authorizer, and every edge carries an honest evidence level.

## Scope

- IAM policy simulator oracle (`SimulatePrincipalPolicy` with resource
  policies supplied) for every `CAN_ASSUME` and `CAN_ACCESS` edge in the lab.
- IAM Access Analyzer external-access findings as a second oracle for
  resource policies.
- `SubjectAccessReview` oracle for every RBAC edge on kind.
- Evidence level assignment: Verified, Derived, Possible, Disputed, exactly as
  the decision tree in `docs/design.md`.
- Disputed edges become regression fixtures automatically.
- Edge-agreement metric computed and written to `docs/accuracy.md`.

## Exit test

```
uv run breachmap verify --lab
```

Edge agreement ≥ 99% on verified edges in the lab. Every Disputed edge has a
fixture under `tests/iam/disputed/`. Every EKS-only edge is labeled Derived.
