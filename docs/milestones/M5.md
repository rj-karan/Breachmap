# M5 — Fix + verify

Due: 2027-02-09

## Goal

Turn a chosen cut into a pull request that provably removes the path and
breaks nothing.

## Scope

- Fix templates for `CAN_ASSUME` (restrict trust `sub`/`aud`) and
  `CAN_TRIGGER` (safe trigger, pinned action, least `permissions`).
- Patch drafter (bring-your-own LLM key, MCP read of the target repo); AI
  never scores or accepts.
- Five deterministic checks: path gone on rebuilt graph, CI/terraform
  plan/actionlint pass, needed access still allowed, no-cheat rules, lab
  replay denied. Max 3 retries, then escalate.
- PR body: path before and after, cost, check results, one-line rollback.
- Lab replay guarded by the `breachmap-lab=true` tag and an allowlist.

## Exit test

```
uv run breachmap fix --lab --dry-run
```

≥ 90% of lab cuts produce a PR that passes all five checks. A patch that adds
`*` permissions or `continue-on-error` is rejected by the no-cheat check in a
test.
