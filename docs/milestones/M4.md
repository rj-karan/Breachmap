# M4 — Paths + min-cut

Due: 2027-01-19

## Goal

Find every attack path from entry points to crown jewels and choose the
cheapest set of edges that cuts all of them.

## Scope

- Virtual attacker and target nodes; bounded simple-path enumeration.
- Path scoring by evidence level, length and what it reaches; path level is
  the weakest edge.
- Fix cost model per edge type (lines changed, downtime risk, dependent
  workloads; "cannot remove" = very high cost).
- Minimum cut on the extracted subgraph; tie-break by blast radius, then
  files changed.
- Separate "needs confirmation" plan for paths through Possible edges.
- CLI path explorer (`breachmap paths`, `breachmap cut`); Next.js dashboard
  starts here if time allows.
- Recall and precision measured against the lab answer key and against
  CloudGoat / pathfinding.cloud scenarios.

## Exit test

```
uv run breachmap paths --fixtures lab/fixtures --answer-key lab/answer-key.json
```

Path recall ≥ 95% and precision ≥ 95% on the seeded lab. The min-cut on the
design-doc example picks the cost-3 cut, not the cost-5 one.
